# DSH 历史图片、附件、模型与节点类型

范围：`codex/multi-runtime-adapters` 工作树，仅本机独立测试节点；没有发布到 VPS、更新正式节点、创建 Release 或重启 Codex/DSH 原生运行时。

## 实现与交付

- DSH 桥新增历史图片、原生文件回执、图片输入、模型及推理强度接口；模型选择与输入按会话串行，输入仍由原生 requestId 去重。
- 历史图片定位绑定原生会话/事件/内容位置，原生附件保留摘要校验；文件图片使用 DSH 预览同一文件 provider。媒体能力与通用文件读取分开。
- SVG 下载保留原文件，静态缩略图使用 `resvg_py==0.5.0`，不读取图中指向的宿主文件或网络资源。BMP/ICO 等通过现有媒体接口传输。
- Android 按能力隐藏快速模式和权限入口，旧节点保留兼容；已保存节点持久化后端类型，项目页、连接设置及切换菜单使用对应官方图标。相册二维码新增纯码识别回退。
- 独立包 `dev.rivo.relay.localtest`，版本 `0.2.108-local.3` / `122`，可覆盖上一测试包并保留配对；不检查或安装正式更新。
