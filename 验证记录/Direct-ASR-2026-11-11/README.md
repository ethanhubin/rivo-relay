# App 直达 VPS 语音验证（2026-11-11）

## 功能与授权

App 向当前已配对节点申请 180 秒语音授权，随后音频与转写直接经过 VPS 到 E2。节点接入密钥、ASR token 不交给 App。每个录音绑定创建时的授权；新录音预留至少 150 秒有效期。音频请求不自动重试、不随聊天路径切换、不回退长路线。

手机配对撤销立即阻止新授权，已签发授权有最多 180 秒有效窗口；撤销节点接入密钥即时拒绝后续请求。获取/续期授权仍需要节点在线；已获授权的音频阶段不依赖聊天节点在线。

- 完整 RelayApi/SpeechRepository 测试先获取授权，然后关闭 MockWebServer 聊天节点；后续音频分片与 finish 仍通过独立 TLS VPS fixture 返回。聊天节点仅收到探测和授权请求，VPS 收到的是语音 grant，不是手机配对令牌。
- 验证错误证书、重定向、失效/篡改授权、节点撤销、不同设备/不同 grant 访问同一流、无关接口越权均被拒绝。

## 真实模型

公网 VPS 已部署 `/opt/rivo-relay/deployments/direct-asr-20261111`，保留上一份 `shared-asr-20261111` 快照。以真实节点凭据签发授权，使用实际 E2 模型识别 5.463 秒合成中文，结果正确。此次发布前测试使用签发函数；发布后的节点 HTTP 签发验证使用 `scripts/asr/verify-direct.py`。

单次顺序对比记录见 `route-comparison.log`：旧路线总处理 5.591 秒，短路线 7.307 秒；finish 分别 0.551/0.446 秒。发送器逐请求创建 TLS 连接，音频非实时推送；推理和网络会波动，这不能证明短路线整体更快，不能用 finish 的降低代替总体性能结论。已确认的是音频绕过聊天节点，且两条路线均正确转写。
