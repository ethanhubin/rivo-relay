## 可复现缺陷与最小修复

成功释放原生订阅后，旧代码保留 `_unmaterialized`、`_active`、`_live` 和待核对终态等局部状态；成功释放进程 writer 时也未完整清除未落盘标记。空闲检查直接扫描这些集合，能够持续阻塞已成功释放的会话。现场亦保留多个成功释放记录；旧运行进程没有直接输出内存集合明细，因此不把该复现表述为对旧进程每个拦截分支的完整观测。

修复只在释放确认成功后清理对应会话的局部状态与交互。释放超时、持锁未释放或其他异常均保留保护。不会发送新的 turn、恢复已释放会话、干预外部 writer，或放宽真实活动会话的空闲检查。
