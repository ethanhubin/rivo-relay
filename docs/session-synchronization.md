# Android 会话同步状态

会话内容与执行状态由 `SessionSnapshot` 表达；连接可用性、读取阶段和权限核验由 `SessionSynchronization` 表达。网络核验不得改写快照中的执行状态或改变运行中消息的分组。

## 状态更新入口

`SessionState.transition(SessionSyncEvent)` 是同步状态更新入口。`stale`、`loading`、`offline`、`readError` 和 `controlNotice` 是只读派生值，不可独立赋值或通过 `SessionState.copy` 修改。

| 事件 | 内容 | 权限 | 同步显示 |
| --- | --- | --- | --- |
| 在线打开 | 保留已有快照，允许加载缓存 | 待核验 | 同步中 |
| 无可用路由 | 保留已有快照 | 待核验 | 离线缓存 / 连接中断 |
| 普通后台读取 | 保留快照 | 保留已核验状态 | 保留任务状态 |
| 读取过慢 | 保留快照 | 待核验 | 同步中 |
| 读取失败 | 保留快照 | 待核验 | 同步失败，正在重试 |
| 事件流中断 | 先处理已收到的增量 | 待核验 | 同步中 |
| 读取成功 | 合并当前有效响应 | 已核验 | 快照中的任务状态 |
| 隐藏页面 | 保留快照 | 待核验 | 下次打开重新核验 |

清除错误提示只影响显示，不能恢复权限。事件流恢复也不能代替权威快照核验。显式传给 `SessionState` 的展示快照默认已确认；控制器的打开路径必须先应用 `Open`，缓存恢复不得应用 `ReadSucceeded`。

## 异步边界

状态转换器不执行网络请求，也不自行判断响应是否过期。控制器在调用转换器前检查会话 generation、权限 epoch 和历史 epoch，分别防止跨页面、跨权限变更和跨历史版本的结果生效。慢请求计时器同样检查权限和历史 epoch。

分页、发送回执、快照合并仍由既有控制器协调；本轮不改写这些算法或服务端协议。现有竞态回归覆盖同会话重开、旧权限响应、历史版本切换与分页。

## 重连与界面

`NodeSessionSync` 是事件流重连的所有者，维护重连延迟和 Last-Event-ID。会话页与后台通知通过 `onInterrupted` 处理错误，保持订阅，不再各自重建连接。没有共享实例的调用方仍使用相同的节点同步实现。

时间线按快照中的 activeTurnId 分组。核验期间保留运行中的活动行，暂停扫光动画；权限栏按最后确认的归属保留并维持最小高度，加载进度条预留固定空间。按钮的可操作性仍以当前核验状态为准。
