# 空闲会话同步与权限边界复查

本次修改位于 `codex/idle-session-sync`，只涉及 Android 会话同步及回归测试，不改服务端协议。目标是让已稳定的空闲会话等待事件，不因普通读取变慢而撤销已核验的操作权限。

## 复查与补修

| 边界 | 最终行为与依据 |
| --- | --- |
| 空闲、运行中与完成 | 空闲不周期读取；运行中保留间隔兜底。事件或显式刷新唤醒，状态稳定后停止轮询；慢读取不积压定时器。 |
| 历史可读但原生状态仍收敛 | `historyReady` 不代表 `nativeReady`；收敛期间继续核对，完成后停止。 |
| 归属与执行状态未确认 | 归属未知、执行未知、释放待完成继续核对；稳定的外部占用、已释放及工作区不可用不被当成运行中的任务。 |
| 队列 | 等待或正在派发的任务保留兜底；不能只看只统计等待项的 `queueDepth`。失败或等待人工恢复的队列不会仅因存在条目而持续轮询。 |
| 普通读取变慢、失败、超时 | 保留已核验权限；失败状态即使错误提示被清除也保留重试。打开、离线、断线、权限/历史变化后的待核验状态不能由慢请求或失败解除。 |
| 事件范围 | 匹配 `threadId`、`conversationId`、嵌套 `thread.id`、`threadIds`；忽略其他会话、空目标列表、待办及项目元数据。无目标 ID 的全局权限、历史和请求通知不能一律丢弃。 |
| 共享事件流 | 中断状态由共享连接保留；中断后才打开的会话仍启用读取兜底。重新连接并取得有效快照后，空闲会话停止轮询。保留 Last-Event-ID 重连机制。 |
| 历史失效与迟到响应 | 立即取消旧详情请求；会话代际、权限代际、历史代际均检查。旧错误不能撤销新权限或触发新的网络恢复。 |
| 访问拒绝、删除与撤销 | 详情或分页的 401/403/404/410 触发重新核验；401 保留由节点处理的约定。删除和 revoked 通知立即失效旧权限。 |
| 迟到的分页拒绝 | 旧权限代际的分页错误不影响新权限，并清理分页请求标记，允许重试。分页与详情仍独立。 |
| 发送回执恢复 | 当前可见会话的接受回执主动唤醒一次读取；不依赖空闲周期轮询清理已落盘占位。 |
| 切换、缓存与暂停 | 复用既有回归验证同会话重开、快速切换、缓存只读、离线恢复及旧请求取消；缓存不直接恢复权限。 |
