# Android 0.2.14 交互优化版

版本 0.2.14 / versionCode 26，沿用此前 debug 签名，可覆盖升级。

- 审批改为独立弹窗，确认操作固定在底部；默认展示审批原因和简短选项，命令详情可展开，长期授权规则在选中后展示。
- 支持稍后处理审批，保留会话内入口。
- 隐藏无正文的分析摘要，修复展开后重复标题；兼容结构化摘要文本。
- 整理持续目标入口，修复持续目标跨轮次时的运行状态与输入行为。

验证范围：191 项 Android 单元测试、APK 和 UI 测试包构建及 lint 通过；334 项服务端回归测试通过。此次没有进行真机或模拟器 UI 验证。

仅发布到主节点 Tailscale HTTP 更新源。
