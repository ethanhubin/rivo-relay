# Android 0.2.20 · Codex 状态、消息与性能完善

版本 0.2.20 / versionCode 32，沿用上一版签名，支持覆盖升级并保留登录与草稿。

- 补齐 writer 断线、未知操作权限、空会话释放、设置缺失和历史恢复边界；保留节点连接状态圆点及两行会话操作栏，详情可查看完整原因。
- 补齐原生工具、协作、推理、计划和错误消息解析；保留未知内容和失败轮次，修正流式顺序、终态及 Markdown 链接、代码块、表格边界。
- 不同会话的队列和操作独立并发；元数据重连不阻塞仍可用的会话 writer，文件上传复用单次辅助连接。
- 历史追加只解析新增记录，仍核验完整旧前缀；减少重复历史 RPC，流式正文更新不再反复废弃已加载旧页。
- 客户端共用节点事件流和并发读取；消息投影、Markdown、图片和磁盘处理移到后台，草稿及提交恢复记录保持顺序和持久化保证。
- 合入并行会话的超时修复：大历史持续传输时不再被 10 秒期限截断，读取允许最多 120 秒、30 秒无数据进展超时；响应较慢时继续保持只读，超时提示不再误写成连接中断。
- 表格和工具列表分批展开，保留完整复制、引用和继续查看；图库按消息复用，无生成图片的会话不再请求媒体库。
- 图片缓存命中不再等待无关下载；媒体校验与索引复用，并保留 Range/ETag、原图重试、保存、分享、编辑及视频后台暂停。
