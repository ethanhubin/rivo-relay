# 0.2.40 / versionCode 52

- 新建会话支持持续目标和可选 Token 预算；只填写目标也可发送，目标随草稿保存并显示在会话列表中。
- 增加目标能力预检和发送前的服务端检查；首条消息确认接收后再启用目标，避免原生目标提前启动轮次。原生目标操作明确标记用户来源。
- 持久化新建、发送和目标设置各阶段；断网或重启后只核对原提交，首条消息已发送时只补做目标设置。未决提交阻止重复发送，并提供结果核对与查看已发送任务入口。
- 修复迟到回执恢复已删除草稿、重启漏查独立目标记录，以及目标完成与末轮完成分开到达造成的重复通知。
- 完善目标编辑失败后的输入保留、预算提示，以及暂停目标、停止轮次、清除目标和保留队列的区别。
- 新建会话入口不再因会话列表刷新而被无关地禁用；会话管理仍要求列表状态已确认。
- 发布流程只核验所选原生主机的身份，避免辅助进程退出误报；补齐部署结果恢复顺序、回滚日志归档断点和已完成发布的服务快照复核。
