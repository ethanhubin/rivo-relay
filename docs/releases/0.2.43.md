# 0.2.43 / versionCode 55

- 增加自建 VPS 中转，与 Tailscale 直连共用一个节点身份和配对授权。App 设置提供自动、仅直连、仅 VPS 三种模式。
- 桌面启动器支持填写公网 IP 和节点授权密钥，自动连接中转并生成 v2 二维码；不需要域名或手机 VPN。
- 网关采用固定证书校验和独立节点密钥，支持流式传输、SSE、取消及断线重连；写请求不自动重放。
- 重新扫描同节点二维码时，通过绑定配对码和访问地址的双向校验保留原设备身份、授权和缓存，不向新扫码地址发送旧 Bearer。
- 更新源可配置直连和 VPS 两条路径，继续校验 APK 大小及 SHA-256；旧二维码和 Tailscale 使用方式保持兼容。

验证：复用本次开发的服务端 60 项、Android JVM 17 项和模拟器端到端结果，详见 docs/validation-vps-gateway.md。最终发布 APK 重新构建并核验版本、上一版签名一致性、更新清单及 HTTP 下载完整性。未运行 lint。项目目录冷读取仍受既有原生历史扫描耗时影响，未在本版优化。
