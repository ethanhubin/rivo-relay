# 0.2.45 / versionCode 57

## 本次更新

- 桌面端首次启动只需粘贴一条 `rivo2.…` 节点接入凭证，自动读取 VPS IP、端口、独立节点密钥和证书指纹。
- VPS 签发命令输出完整凭证，支持自定义端口和 IPv6；旧版 `rivo1.…` 密钥及已保存的 IP + 密钥配置继续兼容。
- 已有密钥可封装成完整凭证，不改变授权；每台桌面仍使用独立凭证。凭证属于私密信息，不随源码或安装包发布。

## 本 Release 同时包含的近期功能

- VPS 中转与 Tailscale 直连双通道，桌面生成二维码，手机扫描连接；旧节点需重新扫描双通道二维码补齐 VPS 配置。
- 设置页可选择自动、仅 Tailscale、仅 VPS，查看实际请求路径、响应状态及检测时间，并手动检测连接。
- 支持从相册识别配对二维码；同节点重新配对可保留有效授权和聊天缓存。

## 安装与桌面配置

下载附件 APK 覆盖安装，或从现有 App 的主节点更新源更新。桌面更新仓库后运行 `./scripts/start-node.sh`，粘贴管理员分配的完整凭证。已有配置无需重新填写；需要替换时使用 `--configure`。完整说明见仓库 `docs/vps-gateway.md`。

## 验证范围

- 本次网关配置及传输共 17 个不同自动化测试通过，覆盖单次粘贴、旧配置、自定义端口、无效凭证、签发、权限及既有传输回归。
- Android 功能代码未改，复用 0.2.44 编译和 14 项相关测试；最终 APK 重新构建，校验版本、与上一版签名一致性及主节点 HTTP 下载完整性。
- 本次未做真机或模拟器界面验证，未运行 lint。0.2.43 的双通道功能曾完成 Android 16/API 37 模拟器验证，详见 `docs/validation-vps-gateway.md`。
