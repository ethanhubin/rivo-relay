# Android 0.2.12 测试版

版本 `0.2.12`，versionCode `24`，包名 `dev.rivo.relay`。沿用 0.2.11 的签名，可覆盖升级并保留登录和本地数据。

- 统一会话操作状态：可操作、外部占用、已释放、工作目录不可用、权限待确认。无权限原因直接显示在会话页面。
- 无权限或状态不可信时，统一禁止输入、附件、语音、模式/设置、发送和队列修改，保留已有草稿。
- 已释放会话增加“恢复操作”，普通恢复不会结束其他进程；强制接管继续使用预览和确认流程。
- 同步超过 3 秒先锁定操作，10 秒超时后重新读取；断线、权限变化和提交结果返回后重新确认，迟到的旧响应不能恢复权限。
- 保留提交结果核对机制，不自动重发结果不确定的写操作。

配套服务端：请更新到本发布标签 `v0.2.12` 并重启 Relay，以启用统一 control 协议及恢复操作接口。旧节点保留只读判断兼容，但不提供新增恢复接口。本次发布未自动部署节点。

验证：186 项 Android JVM 测试、109 项服务端相关测试通过；应用及 UI 测试 APK 构建通过；lint 为 0 错误、42 警告、3 提示。此次未连接实体设备或运行模拟器 UI 测试。
