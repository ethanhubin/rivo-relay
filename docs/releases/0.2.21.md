# Android 0.2.21 · 前台恢复与重连优化

版本 0.2.21 / versionCode 33，签名与 0.2.20 一致，支持覆盖升级。

- 从后台返回时重新建立读取连接，清理可能已经失效的旧连接。
- 后台会话同步使用独立请求队列，每节点最多同时读取两个会话，避免占用前台请求名额。
- 实时事件连接使用独立请求队列；45 秒未收到数据时断开并进入已有重连流程，正常服务端每 15 秒发送心跳。
- 手动重连直接触发会话、目录和待办刷新，不再等待额外的节点探测；目录刷新会取消并等待旧任务退出，避免复用已失效的读取。
- 保留新状态确认后的操作权限校验；重连不取消或自动重发已提交的写操作。

验证：262 项 Android JVM 测试通过（0 失败、0 跳过），Debug APK 构建和 lint 通过；新增实时连接占用队列、12 个后台读取阻塞时前台请求及时完成，以及重连替换卡住目录请求的回归用例。本版没有连接真机或模拟器，未实测手机休眠、Tailscale 路由恢复与现场网络耗时；不宣称已经消除全部连接问题。
