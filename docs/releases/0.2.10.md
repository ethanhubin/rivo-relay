# Android 0.2.10 测试版


- 补齐模型与快速模式、原生审批、恢复面板、草稿与队列恢复、Review/diff 和工作树交互。
- 增加 Desktop 桥接协议、按会话固定的运行时、重连隔离和原生历史修复/回滚。
- 增加图片手势、Media3 音视频、媒体库、生成图片溯源及流式语音输入；补齐取消、超时、凭据隔离和媒体大小边界。
