# Rivo Relay 0.2.84 / versionCode 96

- 修正会话权限重新校验时误显示离线的问题，细化同步、失败重试和等待回应状态。
- 接管操作增加分阶段诊断；失败后保留可核验的失败阶段与状态，避免丢失恢复提示。
- 分离 VPS 与本地 HTTP 连接池，避免并发传输争抢连接；节点明文入口过载时返回 503 与 Retry-After。
- 普通 GET 业务读取增加 30 秒协作式预算，连接断开后释放可取消的锁和只读 RPC 等待；保留已提交写操作的结果核对机制，不强杀原生运行时。
- 新增首响应耗时、白名单请求类别、传输失败阶段及锁等待诊断。SSE、下载和写操作不套用普通读取预算，已开始的修复仍遵循原有超时。

验证：复用本次服务端中转、API、接管、读取预算、过载、writer 与历史回归结果；发布 CLI 执行 SessionControlTest、SessionControllerTest，构建最终 APK 并校验版本、签名连续性、主节点及 VPS 更新清单与下载完整性。部署状态另见 workspace/artifacts/release-0.2.84。未运行 lint 或全量测试。

真机/模拟器验证范围：未进行 Android 真机或模拟器验证；发布后检查 VPS 与可连接节点的部署版本、健康状态和日志。
