# Android 0.2.18 · 会话独立 writer 与释放边界修复

版本 0.2.18 / versionCode 30，沿用上一版签名，可覆盖升级并保留登录与草稿。

- App 执行的会话使用独立 writer；只查看会话不取得写锁。
- 释放暂停目标队列、停止任务并关闭对应 writer，核验实际写锁后才确认成功；其他会话保持运行。
- 审批、断线与恢复绑定 writer 身份，旧审批不串会话，结果未知的任务不自动重发。
- 补齐创建/关闭竞态、子进程清理、通知队列饱和、传输阻塞与历史状态收敛。
- 客户端区分“继续释放”“释放权限”和 Desktop 的“释放订阅”，失败不误报成功。
- 尚未持久化首条消息的空会话会明确拒绝释放并保留 writer，避免关闭后无法恢复。显式 Desktop 共享仍只释放订阅。
