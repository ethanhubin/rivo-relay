# Android 0.2.15 强制接管入口修复

版本 0.2.15 / versionCode 27，沿用此前 debug 签名，可覆盖升级。保留 0.2.14 的审批、活动展示与持续目标改动。

- 无权限时始终显示醒目的“强制接管”入口；断网、待核对操作、共享 Desktop 等暂不可接管情况置灰并直接显示原因。
- 接管预览独立于写权限和历史同步。历史读取过期或卡住时，可单独向服务器重新核验，输入仍保持锁定。
- 缺少历史主机缓存时支持按需核验；主机接管能力每 5 秒重新核验，消除永久失败缓存。
- 强制接管始终先展示影响范围并确认，随后继续执行原有票据、主机、持锁进程核验；不会绕过实际主机限制或自动重发任务。

验证：194 项 Android 单元测试、341 项服务端回归测试通过；APK / UI 测试包构建及 lint 通过。未连接真机或模拟器，新增按钮可见性 UI 回归仅完成编译。

仅发布到主节点 Tailscale HTTP，不推送 Git 或创建 GitHub Release。
