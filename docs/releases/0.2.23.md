# Android 0.2.23 · 会话权限与按需获取

版本 0.2.23 / versionCode 35。

- 进入会话立即核验实际持有者：确认被其他进程持有时显示“强制接管”，确认由自己持有时显示“释放权限”，其他状态不显示权限操作按钮。
- 包含此前已提交的浅色、深色及跟随系统主题设置。
- 移除“恢复操作”入口。已释放会话可编辑并发送消息，发送时正常获取权限；查看会话和后台队列不会自动获取。
- 已释放后仍核验是否被其他进程接手，外部占用可在发送前显示；获取失败不启动任务、不结束其他进程。
