# Android 0.2.16 会话权限与稳定性更新

版本 0.2.16 / versionCode 28，沿用此前 debug 签名，可覆盖升级并保留登录及草稿。

- 聊天设置新增只读、工作区读写、完全访问选项，审批策略可单独选择；支持当前会话修改和按节点保存新会话默认值。
- 权限选择随新会话草稿保存，明确选择“沿用节点默认”不会被本机默认值覆盖；讨论模式保持只读及退出恢复逻辑。
- 优化命令活动摘要和传输大小，手机只接收执行状态；审批仍保留完整上下文。
- 修复本机原生主机身份核验和历史读取，核验实际 socket、进程及状态数据库，避免沙盒内进程查询受限导致历史不可用。
- 汇总此前未提交的审批弹窗、强制接管入口、模型目录和持续目标状态修复。
